# Assets

Fonts, each under the SIL Open Font License 1.1 with its licence beside it:

- `fonts/Inter.ttf`: [Inter](https://github.com/rsms/inter). Licence
  `fonts/Inter-OFL.txt`, from the Inter project's `LICENSE.txt`.
- `fonts/Caveat.ttf`: [Caveat](https://github.com/googlefonts/caveat), a
  handwritten face with a weight axis. Licence `fonts/Caveat-OFL.txt`, from
  the [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/caveat).
- `fonts/PatrickHand-Regular.ttf`: Patrick Hand, a print-style handwritten
  face that stays readable at caption size. Licence
  `fonts/PatrickHand-OFL.txt`, from the
  [Google Fonts repository](https://github.com/google/fonts/tree/main/ofl/patrickhand).
