Sources gathered 2026-10-30.

county-page.txt: Contra Costa County Elections' page for Measure X,
https://www.contracostavote.gov/m9003-en-2/. Read in a desktop Chrome browser
(contracostavote.gov returns a bot challenge to scripted fetches) and saved as text;
the file's header gives how the text was taken. It prints the ballot question, the
County Counsel's impartial analysis, the District's tax rate statement, the argument in
favor, the rebuttal to it, the argument against and the rebuttal to it. The page goes on
to print the measure's full text and bond project list, which are not saved here.
