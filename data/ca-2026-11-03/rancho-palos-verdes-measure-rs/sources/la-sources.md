## County measure list entry

From `county-measure-list-excerpt.txt` (LA County RR/CC final measures list):

> RS Rancho Palos Verdes Public Safety/City Services Measure: To help prepare for and respond to wildfires/natural disasters; maintain roads/storm drains; prevent sinkholes; address landslides/land movement; and support general city services, shall the transient occupancy tax (paid only by hotel/motel guests) be adjusted from 10% to 13%, providing approximately $2,200,000 annually until ended by voters, requiring audits, spending disclosures, all funds benefiting Rancho Palos Verdes which cannot be taken by the State or Los Angeles County, be adopted?
>
> Supporters: PVP Chamber of Commerce, RPV Neighborhood Watch, Wayfarers Chapel, PVP Montessori School, ret. Judge Gregory O'Brien
> Opponents: None submitted.

Vote threshold: Majority 50%+1 (confirmed in the impartial analysis: "takes effect only if a majority... casts a 'Yes' vote").

## What's present vs. missing

- **Impartial analysis**: present (`impartial-analysis.pdf`).
- **Argument in favor**: **missing — not found/not fetched.** The county list names five supporters, so an argument was presumably filed, but Resolution 2026-62 only sets up the filing process; the argument text itself was not located on the city's site or elsewhere.
- **Argument against**: **missing — not filed.** The RR/CC list states "Opponents: None submitted," so no argument against exists to find.
- **Rebuttal to argument for / rebuttal to argument against**: **not applicable.** With no argument against filed, there is nothing to rebut on either side (a rebuttal to the favor argument would require an opposing proponent, which none submitted).
- **Full text**: the code amendment (RPVMC §3.16.030) is described in the impartial analysis; the operative amendment language is expected to be in `resolution.pdf`'s exhibit, but this was not independently re-confirmed line-by-line against the ordinance text — treat as present-but-unverified.
- **Tax rate statement**: **not applicable.** This is a general tax rate adjustment, not a bond measure, so no Prop-13-style tax rate statement applies.
